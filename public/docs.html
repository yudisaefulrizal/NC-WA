REFERENSI INTEGRASI

Dokumentasi API

Satu endpoint untuk satu perintah. Semua API memakai header X-API-Key.

Mulai dari sini

Base URL lokal: http://127.0.0.1:8066. Semua respons sukses berstatus 200. Gunakan HTTPS jika engine diakses melalui internet.

curl http://127.0.0.1:8066/sessions \
  -H 'X-API-Key: KEY_ANDA'

Nomor pribadi: 628123456789. Grup: 1234567890-1234567@g.us atau JID grup numerik tanpa tanda hubung.

Metode dan endpointBody / hasil

GET /sessionsArray id, status, phone

Status: connecting, qr_required, connected, logged_out. Hapus lalu buat ulang session logged_out untuk memasangkan kembali.

Kirim teks dan media

Request menunggu antrean dan hasil pengiriman ke WhatsApp. Respons 200 bukan bukti pesan sudah dibaca atau diterima HP tujuan. Jeda default 1 detik setelah pengiriman sebelumnya selesai, per session.

POST /sessions/toko-a/messages/text
{"to":"628123456789","text":"Halo"}

POST /sessions/toko-a/messages/media
{"to":"628123456789","type":"image","url":"https://example.com/photo.jpg","caption":"Halo","filename":"photo.jpg"}

Respons:
{"messageId":"3EB0...","to":"628123456789@s.whatsapp.net"}

Jenis media: image, document, audio, video. Caption opsional; nama file dipakai untuk dokumen. URL harus HTTP/HTTPS publik. Batas media 32 MiB secara default.

Presence

POST /sessions/toko-a/read
{"from":"628123456789","messageId":"3EB0..."}

POST /sessions/toko-a/typing
{"to":"628123456789","state":"composing"}

Respons: {"ok":true}

State mengetik: composing atau paused. Untuk receipt grup yang belum tersimpan di memori (misalnya sesudah restart), sertakan sender berupa nomor pengirim. Indikator dibaca mengikuti pengaturan privasi WhatsApp.

Webhook dan media masuk

Isi WEBHOOK_URL pada konfigurasi engine. Engine mengirim POST JSON untuk event message, session.status, dan session.qr. Jika gagal, coba ulang 3 kali dengan jeda 1, 2, dan 4 detik. Penerima sebaiknya memproses messageId + sessionId secara idempoten.

{"event":"message","sessionId":"toko-a","messageId":"3EB0...",
 "from":"628123456789","isGroup":false,"groupId":null,
 "sender":"628123456789","type":"text","text":"Halo",
 "media":null,"timestamp":1757808000}

Untuk grup, from dan groupId berisi JID grup; sender adalah pengirim. Alamat LID dipertahankan dengan akhiran @lid bila nomor alternatif tidak tersedia. Jenis media membawa media: {"url":".../media/ID","mimetype":"image/jpeg"}. Unduh melalui GET /media/:id dengan API key; jangan taruh key di URL. File kedaluwarsa setelah 7 hari secara default.

{"event":"session.status","sessionId":"toko-a","status":"connected","phone":"628123456789"}
{"event":"session.qr","sessionId":"toko-a","qr":"data:image/png;base64,..."}

Antrean webhook dan deduplikasi berada di memori, bukan penyimpanan durable. Restart dapat menghilangkan event yang belum selesai dikirim.

Statistik dan error

GET /stats → uptime dalam detik, sessions berisi total dan jumlah tiap status, messages berisi sent dan received. Statistik reset saat engine restart.

{"error":"session_not_connected","message":"Session toko-a belum tersambung"}
HTTPKode error
400invalid_request, invalid_number
401unauthorized
404session_not_found, media_not_found, not_found
409session_exists, session_not_connected
413invalid_request (body terlalu besar)
500internal_error
502send_failed, logout_failed
503queue_full, unavailable

Cocokkan field error, bukan teks message. Batasi body JSON maksimal 64 KiB. Jangan otomatis mengulang request pengiriman yang timeout: pesan mungkin sudah terkirim.
